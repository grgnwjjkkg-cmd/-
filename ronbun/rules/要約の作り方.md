# 論文要約の作り方（エージェント用）

サイト「はしりラボ」（子ども・親・アスリート向けに、スポーツ科学の論文を日本語でやさしく端的にまとめるサイト）の要約を作る。
入力: batches/bXX.json（PubMedの要旨つき論文リスト）。出力: summaries/bXX.json（1ファイル、JSON）。

## 絶対のルール
- 使ってよい情報は、その論文の title と abstract だけ。自分の知識・他の論文の内容で数字や結論を足さない
- 数字（人数・年齢・期間・%・秒・cm・効果量）は abstract にあるものだけ。abstract にない数字は書かない。単位も abstract どおり
- 論文の英文を訳してそのまま並べない。自分の言葉で短く
- 「絶対」「必ず」「誰でも」「〜が治る」は使わない。「〜という結果」「〜の可能性」
- 対象が大人・トップ選手なら、子どもに当てはめない（how_to_use に「子どもで確かめた研究ではない」と書く）
- ケガ・痛み・病気には踏み込まない。触れる場合は「医師や専門家に相談を」

## 除外するもの（skipped に理由つきで入れる）
- 患者・病気の人・高齢者のリハビリ・妊婦など、健康な人のスポーツの話でないもの
- サプリ・薬・ドーピング・ケガの治療・睡眠・食事・体重管理が主題のもの
- テーマとほぼ関係ないもの、abstract が薄すぎて結論が読み取れないもの
- 研究の計画だけ（protocol）で結果がないもの

## 出力の形（summaries/bXX.json）
{"summaries":[ ... ], "skipped":[{"pmid":"...","reason":"..."}]}

summaries の1件:
{
 "pmid": "...", "doi": "...", "field": 入力のfield, "theme": 入力のtheme,
 "status": "確認待ち", "basis": "要旨のみ",
 "headline": "見出し。結論がそのまま分かる文（40字以内）。疑問形でも可",
 "one_line": "ひとこと結論（40字以内）",
 "for_whom": "こんな人向け（例: 足を速くしたい中高生と指導者）",
 "design": "まとめ研究（メタ分析） / まとめ研究（システマティックレビュー） / くじ引きで分けた実験 / 比べる実験（くじ引きなし） / その他 のどれか",
 "who": "だれを（年齢・性別・競技レベル・人数。abstractにある範囲で）",
 "what": "なにをして何と比べたか",
 "period": "期間（abstractにあれば。なければ空文字）",
 "results": ["結果1（数字はabstractどおり）", "結果2", ...  2〜4個],
 "how_to_use": ["練習にどう使う1", ... 2〜3個。研究でやった内容の範囲で],
 "limitations": ["研究の限界1", ... 1〜3個],
 "stars": 1〜5の整数,
 "stars_reason": "★の理由（1文）",
 "verdict": "はい / たぶん はい / まだ分からない / 効果はなさそう のどれか",
 "tags": ["子ども","中高生","大人","トップ選手","女子","男子","サッカー" など該当するもの],
 "citation": {"first_author":"...","year":"...","journal":"...","title_en":"原題そのまま"}
}

## ★の付け方
- ★5: まとめ研究で、結果がそろっていて、研究の質も低くない
- ★4: 人数が十分なくじ引き実験 / まとめ研究だが結果にばらつき
- ★3: 比べる群はあるが人数が少ない / まとめ研究だが元の研究の質が低い（abstractに low certainty 等とある）
- ★2: 比べる群なし・観察だけ・とても小さい実験
- ★1: 意見・解説
まとめ研究でも、abstract に「証拠の質が低い」とあれば★3以下に下げる。

## 文体
中学生が読める言葉。専門用語は言い換える（プライオメトリクス→跳ねる運動、RCT→くじ引きで分けた実験、効果量→効き目の大きさ）。1文は短く。
