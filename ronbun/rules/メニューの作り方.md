# 論文 → 練習メニューの作り方（エージェント用）

筋トレ・スプリント記録アプリ「エビトレ」で、論文の画面から「このメニューで練習する」を押すと、その研究で実際に行われた練習がマイメニューとして保存される。そのためのデータを作る。

入力: 論文リスト（pmid, title, abstract, 要約の headline / what / period / who）
出力: JSON `{"menus":[...], "skipped":[{"pmid":"...","reason":"..."}]}`

## 絶対のルール
- 使ってよい情報は、その論文の title と abstract だけ。自分の知識で数字（セット数・回数・距離・秒・休み・週の回数・期間・重さ）を足さない
- abstract に書かれていない数字は null にする。「3〜4セット」のように幅があるときは小さい方を入れ、note に幅を書く
- 研究でやった内容を写すだけ。「おすすめ」「必ず」「絶対」「誰でも」「治る」は使わない
- 医療・リハビリ・サプリの話はしない

## メニューにしないもの（skipped に理由つきで入れる）
- 練習の内容（種目・回数など）が abstract からほぼ読み取れない
- 低酸素室・特殊な機械・研究室でしかできない練習、授業全体や競技そのもの（試合形式など）
- 1回だけの測定や、直前の準備運動の比較だけで、練習メニューとして続けるものでないもの
- 比べた練習が「何もしない」だけで、練習した側の内容が書かれていないもの

## 1件の形
{
 "pmid": "...",
 "status": "確認待ち",
 "checked": "",                     ← 点検係が "AI点検済み" にする
 "name": "メニュー名（20字以内。例: 片脚レッグプレス（下ろし3秒））",
 "group_label": "研究でこの練習をした組の呼び方（例: 片脚ずつの組）",
 "weeks": 8 または null,             ← 期間（週）
 "per_week": 2 または null,          ← 週の回数
 "items": [
   {
     "exercise": "種目名（日本語。アプリの標準種目にあればその名前をそのまま使う）",
     "tracking": "weightReps / reps / time / distanceTime のどれか",
     "group": "胸 / 背中 / 脚 / 肩 / 腕 / 体幹 / スプリント / ジャンプ / 有酸素 のどれか",
     "sets": 3 または null,
     "reps": 10 または null,
     "meters": 30 または null,
     "seconds": 20 または null,       ← 1セットの時間（プランクの秒数、走る秒数など）
     "rest_seconds": 120 または null,
     "load": "重さや強さの説明（例: 最大の80%、自分の体重、全力）。なければ空文字",
     "note": "やり方の補足（例: 下ろす動きを3秒で）。なければ空文字"
   }
 ],
 "quote": "数字の根拠になる abstract の原文（一字一句そのまま。複数あれば ... でつなぐ）",
 "caution": "注意（1文。例: 筋トレ経験のない大学生男子の研究。体力に合わせて回数を調整する）"
}

- items は研究で行った順。多くても8個
- tracking の決め方: 重さを使う → weightReps / 自分の体重で回数 → reps / 時間だけ → time / 距離とタイム（ダッシュ）→ distanceTime
- 数字（sets, reps, meters, seconds, rest_seconds, weeks, per_week）は、どれも abstract の中に出てくる数字であること（英語の数字表記 three / eight なども可）
- 回数が「全力で」「限界まで」のように数字でないときは null にして load / note に書く

## アプリの標準種目（名前をそろえる）
ベンチプレス, インクラインダンベルプレス, ダンベルフライ, 腕立て伏せ, ディップス, デッドリフト, 懸垂, ラットプルダウン, ベントオーバーロウ, シーテッドロウ, スクワット, フロントスクワット, ブルガリアンスクワット, ルーマニアンデッドリフト, ヒップスラスト, ノルディックハムストリング, レッグプレス, カーフレイズ, パワークリーン, ショルダープレス, サイドレイズ, バーベルカール, トライセプスエクステンション, プランク, アブローラー, 10mダッシュ, 30mダッシュ, 60mダッシュ, 坂道ダッシュ, そり引きダッシュ, ボックスジャンプ, バウンディング, 立ち幅跳び, ランニング

標準種目に無いもの（例: ドロップジャンプ、メディシンボール投げ、20mダッシュ）は、分かりやすい日本語の名前で新しく書いてよい。

## 点検（別の担当が行う）
点検係は、メニューを作った担当とは別のエージェント。1件ずつ abstract と照らし合わせて次を確かめ、直す。
1. items の数字がすべて abstract にあるか（ないものは null にする）
2. 種目・順番・負荷が abstract と合っているか。比べた組を取り違えていないか
3. quote が abstract の一字一句そのままの抜き出しか
4. 除外ルールに当たるものが混ざっていないか（当たれば skipped へ）
5. 禁止の言葉がないか
直したら "checked": "AI点検済み" にする。status は "確認待ち" のまま（人の確認はまだ）。
