# ケメトの秘宝（仮） — 設計メモ

古代エジプトの町を3Dで歩き回り、盗まれた秘宝の手がかりを集める探索アクションRPG。

## 物語（第1章）
- 舞台：ナイル河のほとりの都「メンネフェル」。
- 祭りの夜、神殿から秘宝**「太陽のスカラベ」**が盗まれた。
- 主人公は駆け出しの宝探し屋。神官長に頼まれ、町の人の話から犯人を追う。
- 手がかりの流れ：
  1. 神官長ネフェル（神殿）：事件の説明。「犯人は赤い砂を落としていった」
  2. 市場の子ども アメン：フードの男が船着き場へ走るのを見た（お菓子と交換で教えてくれる）
  3. 露店のおばさん タウィ：お菓子を売っている。武器商人の場所も教えてくれる
  4. 漁師セティ（船着き場）：フードの男は「西岸の墓地」へ渡った。渡し舟には通行証が要る
  5. 衛兵カシュ（西の門）：武器を持たない者は通さない → 武器を手に入れると通れる
  6. 西岸の墓地（ダンジョン）：ミイラやサソリと戦い、奥で盗賊団の頭「黒ジャッカル」と対決
- 第1章のクリアで秘宝を取り戻す。ただし「スカラベは2つで1対だった」という次章への引き。

## 第2章「大ピラミッドの封印」と、ひろがる世界
- ケムの話：月のスカラベの手がかりは、ギザの大ピラミッドの奥の封印された王の間にある。
- 探索の決まった流れ（どの遺跡でも同じ形）：**石板を3つ見つける → 封印の扉が開く → 秘宝を取る → 崩れる前に脱出**。
  - 石板を見つけるたびに、扉の3つの印が1つずつ金色に光る（あといくつかが分かる）。
  - 秘宝を取ると100秒の制限時間。揺れ・地鳴り・落石の中を出口まで走る。失敗しても秘宝は元に戻り、やり直せる。
- 秘宝「ホルスの眼」を持ち帰ると、ギザの「太陽の門」が開き、天空都市へ行ける。

| 場所 | 雰囲気 | つながり |
|---|---|---|
| メンネフェルの町 | 明るい市場と神殿、ナイルの船着き場 | 西門 → 墓地、船着き場の先 → 海中遺跡 |
| 西岸の墓地 | 高さ20mの座像が守る岩の墓、水没した柱の広間、洞窟 | 西の道 → ギザ |
| ギザの台地 | 段々に積まれた高さ150mの大ピラミッド、石の墓の通り | ふもとの穴 → ピラミッドの中、太陽の門 → 天空都市 |
| 大ピラミッドの中 | 盗掘者の穴、高さ17mの大回廊、女王の間と隠し部屋、赤い花こう岩の王の間 | 封印・秘宝・脱出 |
| 海に沈んだ神殿 | 光のゆらぎ・泡・倒れた巨像。水の中はゆっくり動く | 町の船着き場 |
| 天空都市ヘリオポリス | 雲の上の島々、光るオベリスク、金色の太陽神ラー | ギザの太陽の門 |

- 見上げる迫力：建物は人の10倍前後の大きさ。画面の右側を上下になぞると見上げられる。
- 音：場所ごとの環境音（砂漠の風、墓の中のしずく・遠くの足音、水の中の泡）。足音は地面で変わる。
- 世界地図：メニューの「地図」から、行ったことのある場所へ移動できる。

## 遊びの仕組み
| 仕組み | 内容 |
|---|---|
| 移動 | 左下のスティックで歩く・走る。カメラは主人公の後ろから追いかける |
| 会話 | 人に近づくと「話す」ボタン。名前・顔・文字送り・選択肢つき。話すとフラグが立ち、ヒント帳に書き込まれる |
| ヒント帳 | 集めた手がかりと「今やること」。画面上部に次の目的を表示 |
| 戦闘 | その場で戦うアクション。攻撃ボタン（3連撃）と回避ボタン。敵は攻撃の前に予備動作を見せる |
| 武器の編成 | 武器1つ＋お守り2つ。武器ごとに攻撃力・速さ・リーチが違う（剣・槍・斧・短剣・鎌剣・弓） |
| ガチャ | 「神託の壺」。ゲーム内通貨「アンク」で引く。**確率を画面に表示**。同じものが出たら強化（＋1） |
| 通貨 | 敵・宝箱・依頼でアンクがもらえる。※最初は現実のお金では買えない（課金は後で検討） |
| 保存 | 自動保存（端末の中） |
| BGM・効果音 | 町・墓地・戦闘で曲が変わる。エジプト風の音階で、コードで作曲・演奏するのでライセンスの心配なし |

## 技術
- ゲーム本体は Web 技術（three.js）で作り、iOS アプリの中の WebView で動かす。
  - Linux 上のブラウザで実際に動かして、画面の確認・自動テスト・プレイ動画の撮影ができる。
  - キャラは本物の3D骨格アニメーションで動くので、コマ送りのぎこちなさがない。
- 人物は MakeHuman（CC0）でリアルな体を作り、服・首飾りを付けて書き出す（`tools/chars/make_human.py`）。アニメは共通のものを骨の向きを合わせて使う。
- 場所は Blender で形を作り、光の跳ね返りを計算して画像に焼き付ける（`tools/bake/`）。
- 建物・ピラミッド・オベリスク・砂漠は、エジプトらしい形をコードで作る。
- iOS 側は SwiftUI＋WKWebView。独自の URL スキームでゲームのファイルを読み込む。
