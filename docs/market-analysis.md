# 筋トレ記録アプリ 競合分析（2026年9月）

評価とレビュー件数は iTunes Search API とカスタマーレビューRSSから取得。筋トレMemo以外の円建て価格は未確認のため、ドル表記。

## 比較

| アプリ | 評価（件数） | 価格 | 強み | 不満の多い点 |
|---|---|---|---|---|
| 筋トレMemo | JP 4.65（約5.1万） | 無料＋広告、プレミアム月300円 | 国産、シンプル、X連携 | 2026年9月の変更（種目追加と過去履歴の有料化、画面遷移ごとの広告）への批判が集中 |

## レビューで多い不満

1. 無料機能の後出し有料化と、広告の多さ
2. Apple Watchの同期不良・機能不足
3. 種目ライブラリが少なく、カスタム種目に制限がある
4. AIの提案が的外れなのに、オフにできない
5. サブスクの価格と、解約・返金のトラブル
6. 入力の自由度が低い（セット数の下限、秒単位、過去日付、並べ替え）
7. データ消失、オフラインで使えない
8. アップデートでの改悪と不具合

## 市場の空白 → このアプリの差別化

| 空白 | このアプリでの対応 |
|---|---|
| 「なぜこのやり方なのか」の根拠を示すアプリがない | **論文タブ**。種目ごとに関係する研究を表示する |
| 筋トレとスプリントのタイムを一緒に記録できない | **距離×タイムの記録**。ダッシュやジャンプの種目を最初から用意し、タイムは短いほどベストとして扱う |
| 筋トレMemoからの乗り換え需要 | **広告なし・コア機能は無料・種目追加は無制限** |
| 海外アプリの翻訳UIと海外式の種目名 | 日本語の種目名と部位分類 |
| オフラインとデータ消失への不安 | 端末内に保存（SwiftData）、**CSVで書き出し** |

## MVP（v0.1）に入れたもの

- 前回値の自動入力（プレースホルダー表示＋1セット目に前回値をセット）、「前回と同じメニューで開始」
- 1セットから記録可、過去の日付・内容の修正可
- 休憩タイマー（±15秒、終了時に通知）
- 自作種目を無制限に作成
- 種目別のグラフ（推定1RM / 回数 / 時間 / ベストタイム）と自己ベスト。無料・期間制限なし
- 自己ベスト更新のお知らせ、連続日数、今週の回数
- 論文タブ（カテゴリ、検索、ブックマーク、原著DOIリンク、サイトのJSONから自動更新）
- CSV書き出し、広告なし

## 次のバージョンの候補

- Apple Watch での記録（Watch 側で完結する入力）と HealthKit 連携
- iCloud 同期、CSV 読み込み（他アプリからの乗り換え）
- ルーティン（テンプレート）と種目の並べ替え
- RPE（主観的運動強度）の入力
- 部位ごとの週ボリューム表示（論文の「週10セット」と連動）
- 収益化：コアは無料のまま、分析機能と論文の全文要約を有料（買い切り or 年額）にする案
